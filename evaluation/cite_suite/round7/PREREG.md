# 第 7 轮预注册 · 引用真伪两臂对照（套件 A）

> 写于 2026-10-26，**在任何一臂运行之前**。目的：先固定假设、臂、指标与判定线，防止看到结果后改口径。

## 1. 研究问题

在**证据完全相同**（同一份报告 + 同一批来源快照）的条件下，逐条核验 12 条引用的真伪：

- **H1（工具增量）**：带确定性工具（`cite_check`）的一臂，引用问题检出率比裸模型一臂高 **≥ 20 个百分点**。
- **H0（无增量）**：差距 < 10 个百分点，或工具臂误伤更多。

## 2. 两臂定义

| 臂 | 输入 | 说明 |
|---|---|---|
| **B 裸模型臂** | 报告 + 4 个来源页面全文快照 | 提示词只说"审计这些引用，逐条判断是否可靠，指出问题"。不给检查清单、不给工具、不给问题条数 |
| **F 工具臂** | 报告 + 同一批快照 + `cite_check` 逐条输出 | 模型的任务是把工具判定整理为最终 JSON；工具与模型冲突时以工具为准 |

- 同一基座模型（当前会话模型），独立上下文，各 **3 次重复**。
- 证据以离线快照提供：对 B 臂是"慷慨基线"（无需联网即可看到页面全文），因此若 B 仍漏检，结论更强；若 B 全对，则 H1 不成立。

## 3. 套件

`ground_truth_cite.json`：12 条引用 = 3 条真实 + 4 条伪造/不可达 + 3 条摘录张冠李戴 + 2 条时序不可能。B 臂提示词不透露条数与分布。

## 4. 指标（主/次）

1. **主指标**：verdict 准确率（PASS/FAIL 判定正确；满分 12）。
2. **次指标**：问题类别准确率（仅对 FAIL 项：unreachable / excerpt / temporal）。
3. **误伤**：把真实引用判为 FAIL 的条数。
4. 报告 3 次的中位数与极差（稳定性）。

## 5. 判定线（先写死）

- F 臂预期 12/12（确定性工具；允许模型转写误差，但不得低于 11/12）。
- **若 B 臂中位数 ≥ 10/12**：判定"H1 不成立"——在引用场景上，裸模型+全量证据也能接近满分，对外不得宣称引用核验优势。
- **若 B 臂中位数 ≤ 9/12 且 F ≥ 11/12**：H1 成立（差距 ≥ 3 条 = 25pp），可作为"工具增量"证据；对外表述限定为"引用真伪"，不外推为"全面检出领先"。
- 误伤：B 臂误伤 ≥ 1 条时单独注明；F 臂误伤应为 0。

## 6. 已知局限（必须与结果一起写）

- B 臂是**同一基座模型的独立会话**，不是外部厂商模型；结论只说明"工具增量"，不说明"跨模型领先"。
- 离线快照消除了反爬/登录/动态渲染，真实联网只会更难——对本套件是**高估**基线能力的方向。
- 样本 12 条，只覆盖引用三类问题；不含"引文支持但结论外推过度"的语义层问题。
- 评分者（本会话）知道密钥，但判定由脚本机械完成，原始输出全部留档（`runs/`），可复核。
