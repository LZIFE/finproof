# FinProof 演示数据来源记录（Phase 1）

> 本目录保存演示用的**真实公开披露文件**（交易所原始 PDF，未做任何修改）。
> 文件哈希在归档时记录，用于校验文件未被篡改；后续金标准的页码与数值均以本目录文件为准。
> 下载工具：`scripts/download_cninfo.py`；提取测试工具：`scripts/check_pdf.py`。
> 数据源说明：巨潮资讯查询接口（`www.cninfo.com.cn/new/hisAnnouncement/query`）在本机测试返回空结果，因此改用**深交所官方披露接口**（`www.szse.cn/api/disc/announcement/annList` + `disc.static.szse.cn/download`），来源同样为交易所原始披露，可追溯。
