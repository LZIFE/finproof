# 主张分类体系（Claim Taxonomy）

> **适用范围（v2.0.0）**：**商业分析类报告**——行业研究、市场分析、竞品分析、商业模式分析、公司深度研究、尽调报告、商业计划书、投资备忘录、财务分析；其中**金融/上市公司研报是验证最深的场景**。
> A–G 七类的定义为通用语义（原始数字 / 计算 / 口径 / 业务事实 / 因果 / 比较 / 预测观点），财务示例仅为便于理解；商业分析类主张同样落入对应类别。

把报告拆成相互独立、可核验的结构化主张，是 FinProof 的方法论基础。系统**不能**把整篇报告直接交给大模型判断，而应先拆解。

## 一、七类主张（A–G）

| 类型 | 说明 | 核验重点 | 商业分析报告示例 |
|---|---|---|---|
| **A 原始数字主张** | 直接陈述的数值 | 数字 / 单位 / 量级 / 期间 / 合并或母公司口径 | "2025 年营业收入 120 亿元"；"截至期末门店 334 家"；"会员数 4200 万" |
| **B 计算型主张** | 含同比/环比/比率等推导 | 需取两个期间数据重新计算 | "收入同比增长 20%"；"2022–2025 年 CAGR 约 74%" |
| **C 口径型主张** | 涉及单季/累计、归母/扣非等 | 原披露的是哪种口径 | "第二季度净利润为 5 亿元"；"自有 IP 占比 56.7%" |
| **D 业务事实主张** | 定性业务结论 | 是否有披露支撑（市占率、客户结构、产能、渠道） | "市场份额提升至 4.8%"；"海外业务已成为第二增长曲线" |
| **E 因果型主张** | 归因型结论 | 原始材料是否支持所引原因、是否有机制性表述 | "毛利率上升主要由原材料价格下降推动"；"增长源于渠道下沉" |
| **F 比较型主张** | 同业/对标比较 | 对标对象、指标、期间、口径是否可比 | "盈利能力显著高于同行"；"坪效为同业龙头的 1.6 倍" |
| **G 预测和观点** | 前瞻/主观判断 | 标记预测/假设/主观，核查是否披露依据 | "未来三年利润将保持高速增长"；"该模式具备规模复制能力" |

> **G 类处理原则**：不得简单判真或假，应标记为「预测 / 假设 / 主观判断」，并核查是否披露预测依据。
> **依据披露显式标注（v2.6.0 硬规则）**：每条 G 类主张的结论行必须标注「依据已披露」（附依据证据编号）或「依据未披露」，不得静默归入"不判真假"；依据未披露的进需用户自核清单（G3）。
> **预测事实化（v2.6.0 硬规则）**：带确定性措辞（"已无悬念/确定性强/板上钉钉/必然达成"等）的前瞻表述，视为把预测包装成事实——结论仍为 OPINION_OR_FORECAST，但**必须列入审计结论问题项**（问题写"预测事实化：确定性表述但依据未披露/不足以支撑确定性"），不与普通 G 类一起静默收口；所依赖基期数字有误时，就基期单独判 REFUTED。
> **G 类不计入评分分母**（无从判真假），但**商业分析报告中 G 类占比通常很高**——若 G 类占比超过 50%，须在摘要中提示"本报告可核验事实密度偏低"。

### 商业分析报告的三类高频陷阱

1. **口径偷换**：把"自主产品（自有+授权）占比"写成"自有 IP 占比"；把"批发口径"与"零售口径"混用；把"市场份额（按 GMV）"与"按收入"混用。
2. **对标可比性缺失**：拿不同市场、不同商业模式、不同会计口径的公司直接比倍数，却不说明差异。
3. **因果当事实**：两件事同期发生（"毛利率升 + 原料降价"）就写成因果（"由原料降价推动"）——E 类必须验证机制。


## 二、主张结构化对象

每条主张转化为如下结构（来源 `backend/app/prompts/claim_extraction_v2.txt`）：

```json
{
  "claim_id": "CLM-001",
  "original_text": "公司2025年第二季度收入同比增长35%",
  "claim_type": "calculated_financial_metric",
  "entity": "示例公司",
  "metric": "营业收入",
  "value": 35,
  "unit": "%",
  "period": "2025Q2",
  "comparison_period": "2024Q2",
  "scope": "consolidated",
  "currency": "CNY",
  "risk_level": "high",
  "source_location": { "page": 3, "paragraph": 2 }
}
```

结构化后，系统才能分别调用搜索、财务计算和矛盾检测模块。

## 三、主张提取规则（节选自 claim-extraction 提示词）

1. 只提取可独立验证的主张；不提取标题、目录、过渡句、空泛形容、情绪表达、表头、公司基本介绍。
2. 复合主张必须拆分（如"收入同比+15% 且海外占比>50% 且由智能家居推动"拆三条），但不过度拆分。
3. 保留原文（source_text 逐字），并生成规范化主张（normalized_claim，如"收入"→"营业收入"）。
4. 增长率必须绑定指标与期间，不得输出无归属的"同比增长 38%"。
5. 子句不得丢失父句的实体/指标/时间。
6. 同一指标+期间+数值只输出一条，不重复。
7. 观点/预测/因果必须正确分类（claim_nature 与 claim_type 匹配）。
8. 未知字段返回 null，不编造；不补写报告外信息；不判断真假、不搜外部。

完整提示词见 `references/claim-extraction-prompt.md`。
