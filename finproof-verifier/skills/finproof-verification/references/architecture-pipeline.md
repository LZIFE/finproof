# 本专家的架构、流水线与能力边界（architecture & pipeline）

> 本文件描述**专家本身**（对话内运行的 Agent）的架构与边界。
> `backend/` 的 Python 服务是**参考实现（历史）**，不是本专家的运行时依赖——本专家不需要任何前端网页或独立后端即可完成核验。

## 一、混合核验架构原则（铁律）

FinProof **不是纯规则系统，也不是纯大模型系统**，而是混合核验架构：

- **确定性程序负责**（可复现、可测试、可解释）：数字格式标准化、单位/币种换算、同比/环比计算、累计转单季推导、财务比率、数值差异比较（含容差）、计算过程记录。运行载体：`bin/finproof_calc.py`（Python `decimal` 精确十进制）。
- **大模型负责**（语义理解与判断）：主张拆解、指标/期间语义识别、非结构化证据理解、证据支持关系判断、因果过度推断检测、预测事实化检测、修订建议。
- **无 API Key 的兜底**：走明确标识的 **Mock 模式**（`FINPROOF_LLM_MODE=mock`），结果带"Mock 模式，非真实模型输出"标识，**不得伪装成真实模型结果**。

## 二、本专家的实际分层（对话内 Agent 形态）

```text
受理 + 范围判定门（Scope Gate：本地 / 联网，由用户拍板）
    ↓
文档解析层（文本直抽 pypdf/pdfplumber → 渲染 + 本地 OCR → 多模态视觉读取）
    ↓
主张拆解层（规则初筛数字型 + 模型语义拆解 A–G；编号按原文出现顺序）
    ↓
结构化归一化层（数字 / 期间 / 单位 / 币种 / 口径）
    ↓
证据检索层（用户上传文件 + 联网检索；混合召回 + 证据门；定稿前链接存活复验）
    ↓
确定性复算层（bin/finproof_calc.py，decimal 精确算，输出公式+输入+差异；判定标〔引擎复算〕并留命令与输出）
    ↓
八步判定链 + 对抗性防御叠加（数值守卫：冲突即 REFUTED）
    ↓
独立复核层（v2.5.0：问题项逐条 + 支持项抽样的盲复核；异源第二模型经子代理优先，同源兜底，分歧披露）
    ↓
评分与输出层（五维加权 FinProof Score + 主张卡 + G1–G4 自核清单 + 对抗性抽查 + 独立复核段 + 审计轨迹）
```

**关键设计**：共 9 层。第 6 层（确定性复算，程序）与第 7 层（八步判定链，模型语义）两条链路**互不覆盖**——数字走确定引擎、语义走模型；数值冲突受守卫保护，语义判断无权翻案。第 8 层独立复核是对**第 7 层判定结论**的第二双确认，不重算分数（评分公式是确定性的，复核只核对分子分母与主张清单的对应）。

## 三、单次核验流水线（数据流）

```text
用户提供待审报告（+ 建议一并提供年报/招股书/公告原文等证据）
  → 范围判定门：确认本地 / 联网模式
  → 解析：抽文本；扫描件走内置 OCR（渲染 + tesseract chi_sim / 多模态视觉）
  → 提取：拆解为结构化主张 A–G，标注类型/期间/口径/单位/币种/风险等级
  → 归一化：数字、期间（YYYYFY/H1/Q1-Q4）、单位、币种、口径
  → 检索：定位支撑/反驳该主张的证据段落与页码；证据门 strict scope 归因避误拒
  → 复算：确定性引擎重算（同比 / 累计转单季 / 比率 / 单位币种换算）
  → 判定：八步链 → 六类结论；叠加对抗性五类检查
  → （仅联网模式）需求判定门 → 联网补证 → 聚焦再搜索（≤2–3 轮）
  → 独立复核：问题项逐条 + 支持项抽样盲复核（异源模型经子代理优先，见 independent-review.md）；分歧逐条披露
  → 评分：五维加权 FinProof Score（附五维明细 + 扣分清单）
  → 输出：主张卡 + 自核清单 + 对抗性抽查 + 独立复核段 + 审计轨迹（含引擎命令）
```

## 四、能力边界（本次更新，替代旧版过时口径）

| 能力 | 状态 | 说明 |
|---|---|---|
| 文本型 PDF 解析 | ✅ 支持 | pypdf / pdfplumber 文本直抽 |
| **扫描件 / 图片表格 / 乱码 PDF** | ✅ **支持（内置 OCR）** | pypdf 直抽 → PyMuPDF 渲染 150–300dpi PNG + 本机 tesseract `-l chi_sim` → 无 shell 时多模态视觉读取 → pdfplumber `extract_table` 恢复表格。已实测中文可用。**仅加密/损坏/模糊到手写级仍归 G4。** |
| **联网检索一手来源** | ✅ **支持** | WorkBuddy 内置 WebSearch/WebFetch，零配置、无需登录；v2.5.0 起定稿前对证据 URL 逐条存活复验 |
| 向量库 / 语义检索 | ⚠️ 降级 | 无 Embedding 服务时降级为关键词 + 指标精确匹配，**如实说明，不伪装** |
| 多智能体编排 | ❌ 不做 | 实为流水线步骤，如实命名，不伪装。**唯一例外（v2.5.0）**：独立复核可经宿主子代理派发**一个**第二模型盲复核（单一复核子步骤，不是多智能体编排），无此能力则同源盲复核或如实标注未复核 |
| 自动生成修订版报告 | ❌ 不做 | 只给"修改建议"文本 |
| 长文档分片 / 断点续审 | ❌ 未实现 | 主张数 >25 时走**分批审协议**（见 SKILL.md 第十节） |
| 批量队列 / 版本 diff | ❌ 未实现 | 一次一份报告、一个会话 |

> **本次修正的过时条款**：
> - 旧版写「假装支持扫描件/OCR（未实现，文本型 PDF 为空则明确报错）」——**已过时**，自 v1.4.1 起内置 OCR 已实现并实测。
> - 旧版写「假装全网搜索/自动找财报（只核验用户上传的证据文件）」——**已过时**，自 v1.1.0 起支持联网核验，v1.3.0 起有聚焦再搜索。

## 五、"禁止假装"清单（宁可少做，不可假装）

- 假装配了 Embedding / 向量库（无服务时如实说明已降级为关键词匹配）
- 假装多智能体编排（实为流水线步骤，如实命名）
- 假装已做 OCR / 假装已联网（联网证据必须标来源 URL + 抓取时间）
- 假装自动生成修订版报告（只给"修改建议"文本）
- 假装大模型核验（无 Key 走带标识的 Mock）
- **假评分**（无五维明细、无扣分清单、无法复算的分数，一律不可接受）
- 编造演示数据（数字须来自真实披露，错误须逐条记录金标准）
- 把"核验不了"伪装成"通过了"

## 六、主要风险（已知，如实披露）

| 风险 | 等级 | 缓解 |
|---|---|---|
| 检索召回缺口 | **高（实测 81% 的错误归因于此）** | 聚焦再搜索 2–3 轮；G1–G4 缺口分类 + 自核清单；不静默少搜 |
| PDF 表格/扫描解析不稳定 | 中 | 内置 OCR 三级降级；识别结果交叉复核并标"±1 字符误差"；加密/损坏仍归 G4 |
| 误报（把对的判成错） | 中 | 保留"无法判断/证据不足"兜底；容差 0.1%+舍入豁免；证据门 strict scope 归因防误拒；独立复核抽检支持项 |
| 漏报（把错的放过） | 中 | 对抗性五类检查（含容差明细、口径双栏、单位确认、因果、引用三对齐）；独立复核逐条复核问题项 |
| **自评闭环（同一模型又判又评）** | 中（v2.5.0 起有缓解） | 独立复核层：异源第二模型经子代理盲复核（如主审 GLM-5.3 + 复核 GLM-5.3-Flash），无则同源盲复核；分歧逐条披露；评分仍声明自评性质 |
| 分数被误读为"结论正确性认证" | 中 | 强制附固定警示 + 自评声明 + 五维明细 + **档位行问题项计数**（见 `scoring-spec.md` §五/§7） |
| 证据链接失效 | 中 | v2.5.0 起定稿前逐条存活复验（状态缀于链接字段，不可达降一档并保留原摘录） |
| 主张过多导致轮次超限 | 中 | 分批审协议（>25 条先出计划再分批）；联网检索硬预算 ≤40 次 |
| 评测口径失真 | 中 | 金标准须同时含错误/正确/证据不足三类样本（见 `demo-evaluation-lessons.md`）；错误召回率按未验证披露，不得以 F1 暗示达标 |
| 范围蔓延 | 中 | 严守"事实核验"边界，不做投资建议、不做原创研究 |
