# 弃权专项（20 例）

测的是 `claim_gate` 的三态边界，不是"模型能不能猜对"：

- 应弃权 14 例：缺值、缺单位、未知单位、缺期间、期间无法解析、无证据、期间/指标错配、来源未核验、证据冲突、单位类别/量纲/比率口径不可比、证据条目缺值/缺单位。
- 应通过 4 例：跨单位、物理单位、容差内、未要求来源。
- 应反驳 2 例：同期间明确错值、正负方向相反。

运行：`python3 run_abstention.py`。输出 `score.json`，按 expected 分三组计数，不把"弃权"混进"支持"。

边界：这 20 例是手写的可判性边界，不替代模型在环的弃权测试；Track B 的 1,470 项见 `../anamnesis/trackb_abstention.py`。
