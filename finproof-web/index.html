立即体验

粘贴报告，跑一次事实核验

本页调用的核验流程使用你自己的 OpenAI 兼容 Key——密钥仅在你浏览器与对应大模型服务之间传递，本服务不存储、不留痕、不替你付费。支持 OpenAI、DeepSeek、通义、智谱等兼容接口（填对应 base_url 即可）。

提示：报告越长、主张越多，LLM 调用越久（约 10–60 秒）。Key 不会离开你的浏览器。
网页版 MVP 范围说明：本页做「主张拆解 → 确定性复算 → 六类判定 → 五维评分」核心闭环；不含联网检索一手来源，因此「来源权威性 / 时间口径一致性」两维为估算值（结果中标注 estimated），不冒充完整专家能力。完整联网核验请在 WorkBuddy 内使用「鉴融 FinProof」专家。
自带 API

同样的核验能力，直接调接口

除了网页体验，任何系统都能直接调用 POST /api/verify 拿到结构化审计报告 JSON。LLM 凭据同样由调用方自带。

请求

POST /api/verify
Content-Type: application/json

{
  "report": "报告全文……",
  "api_key": "sk-你的密钥",
  "base_url": "https://api.openai.com/v1",
  "model": "gpt-4o-mini"
}

curl 示例

curl -X POST https://<你的域名>/api/verify \
  -H "Content-Type: application/json" \
  -d '{"report":"...","api_key":"sk-...","model":"gpt-4o-mini"}'

返回（节选）

{
  "ok": true,
  "score": { "score": 86, "dims": {
      "coverage": 100.0, "accuracy": 55.6,
      "citation": 100.0, "authority": 40.0,
      "time_scope": 86.7 },
    "estimated_dims": ["citation","authority"] },
  "verdict_distribution": {"支持":9,"反驳":2,"证据不足":1},
  "claims": [
    { "id":"1","type":"B","text":"……",
      "verdict":"REFUTED","verdict_cn":"反驳",
      "recompute": {"kind":"yoy",

  ]
}
返回字段与专家审计报告同构：每条主张含 type / verdict / recompute / reason；score 五维中 citation、authority 为 MVP 估算项。
