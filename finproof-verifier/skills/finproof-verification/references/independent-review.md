# 独立复核协议（Independent Review Protocol）

> 目的：打破**自评闭环**——同一模型既拆解主张、又下判定、又给来源定级、又打分，单模型的盲区会贯穿全链路。本协议在判定完成后引入**第二个判断者**对结论做盲复核，把"单一模型说了算"变成"双通道交叉确认，分歧可见"。
> 状态：v2.5.0 起为**必做环节**（`SKILL.md` 第六节）；做不了必须如实标注，不得伪装。

---

## 一、复核什么（范围）

| 对象 | 要求 |
|---|---|
| **全部问题项** | 反驳 / 证据不足 / 部分支持 / 无法判断 / 预测事实化（G 类标记性问题项）——**逐条复核**。这些是报告的结论承重墙，也是最容易被单模型误判的地方 |
| **支持项抽样** | `max(3, ⌈10% × N_d⌉)` 条，按主张风险分降序抽取——防止"把错的判成对的"（假阳性支持）被无声放过 |
| **评分复算** | 五维公式的分子/分母与主张清单是否对应（机械核对，复核方按 `scoring-spec.md` 公式重算总分） |

**不复核**：普通观点/预测类（G 类不判真假；**预测事实化的问题项除外**——它们已进问题项清单，须复核）、纯格式问题。

## 二、怎么复核（盲输入，防锚定）

给复核方的输入**只含原料，不含主审结论**：

```text
【待复核主张 #N】报告原句（逐字）
【证据】[E##] 逐字摘录 + 证据等级 + 来源类型 + 定位
【复算数字】报告值 / 复算值 / 绝对差 / 相对差%（含判定来源标记：引擎复算 or 心算）
【问题】仅依据上述材料，该主张应判：支持 / 反驳 / 部分支持 / 证据不足 / 观点或预测 / 无法判断？给出结论与一句话理由。
```

**禁止**向复核方提供：主审的结论、理由、风险分、扣分记录——任何先验都会锚定复核，使其退化为"附议"。

**摘录充分性要求（v2.6.1 实测教训）**：盲输入的摘录**必须包含来源的裁定句**（fact-check 的评级结论句/披露的关键句）；仅有过程性描述摘录时，复核方对**否定式主张**（"X 并未…"类标题）误判率显著上升（Fin-Fact C08/C09 实测：仅凭单条过程摘录判反方向）。摘录不含裁定句 → 复核方须回读来源原文再判，不得只凭摘录断言。

## 三、谁来复核（四档，按可用性降级，如实标注）

| 档位 | 条件 | 报告标注 |
|---|---|---|
| **① 异源复核（首选）** | 宿主提供子代理/第二模型调度能力 | 〔独立复核：异源 · {{模型名}}〕 |
| **② 同源盲复核（兜底）** | 无第二模型，但可开冷上下文（新会话/清空上文）重新判定 | 〔独立复核：同源盲复核，削弱有限〕 |
| **③ 自检复核（机械层兜底，v2.6.0 起）** | 连冷上下文也开不了——单机单轮次的最低保障；**成本近零，①②可用时也建议叠加** | 〔自检复核：引擎重跑 N/N 一致 · 摘录复读 N/N 一致 · 口径核对 ✓〕 |
| **④ 未复核（如实）** | 无 shell 且无源文可复读 | 〔本次未经独立复核 + 原因〕 |

**异源复核示例**：主审模型 GLM-5.3，经子代理（subagent）派发复核任务给 **GLM-5.3-Flash**——不同模型族的训练数据与偏差不同，"同一处证据歧义两个模型一起看错"的概率显著低于单模型自审。派发时把第二节的盲输入作为子代理的全部输入，并要求其只回「结论 + 一句话理由」。

**自检复核协议（第③档）**：输出前对**每条 REFUTED 与全部扣分项**机械执行三步——
1. **重跑引擎命令**：逐条重新执行审计轨迹里的 `finproof_calc.py` 命令，核对两次输出完全一致；
2. **复读证据摘录**：把主张所引逐字摘录与源文件/来源原文再比对（防"摘录与原文不符"——这是复核能揪出的最典型事实性错误）；
3. **核对统计口径**：扣分清单的数字与统计口径表逐一对上。

**边界（必须随标注写明）**：自检复核只防**机械性事实错误**（算错、抄错、统计对不上），**不能发现语义误判**——它介于异源复核与未复核之间，但不是独立判断。发现不一致时回查原料，错了就改，并在标注里如实计数（如"引擎重跑 4/5 一致，1 处已修正"）。**不得把自检复核写成"已复核"或"独立复核"**。

**为什么兜底也要做**：同源冷上下文盲复核虽不能消除模型级盲区，但能暴露"上下文污染"（主审前文推理把复核也带偏）与自相矛盾；自检复核连这层都够不到时，至少保证"反驳结论的数字与摘录本身没有低级错误"——聊胜于无，且成本极低。

## 四、分歧怎么处理（披露优先，不静默采纳）

1. **一致**：复核结论与主审相同 → 计入"一致"，报告只给计数。
2. **分歧**：逐条列出——`#N · 主审判 X（证据链/引擎轨迹）· 复核判 Y（一句话理由）· 分歧点`。
3. **裁决原则**：主审结论保留（其证据等级、引擎复算轨迹可查、可复算），**除非**复核指出主审证据链中的**事实性错误**（如摘录与原文不符、复算数字错误）——此时必须回查原料，错了就改，并在报告「独立复核」段记录修正。
4. **禁止**：静默采纳复核方、静默维持主审、或把分歧写成"已协商一致"。分歧是信息，不是噪音——它告诉用户"这条结论存在合乎程序的争议"。

## 五、报告落点（audit-report-template.md「独立复核」段）

```text
独立复核
  复核方式：异源 · GLM-5.3-Flash（经子代理盲复核）/ 同源盲复核 / 自检复核〔机械层：引擎重跑 N/N 一致 · 摘录复读 N/N 一致 · 口径核对 ✓〕/ 未复核（原因）——可组合（如 异源 + 自检层）
  复核范围：问题项 3/3 条 + 支持项抽样 3 条 + 评分复算 ✓
  结果：一致 5 条 · 分歧 1 条
  分歧明细：#5 主审判「部分支持」（证据 4.5% vs 报告 4.8%，"提升"无据）· 复核判「反驳」（差 6.7% 超容差）
           → 分歧点：0.3pp 差值按口径应走 0.5pp 容差还是比率 0.1% 容差；主审结论保留，理由见主张卡
```


## 七、异源复核实测记录（v2.7.1，2026-10-26）

**首次跨模型盲复核实测**：主审 GLM-5.3（Fin-Fact batch5 全 10 条，含 6 问题项）→ 复核 GLM-5.3-Flash（glm53-flash 子代理，盲输入=主张+证据摘录+链接，**不含主审结论**，可联网自查）。

| 结果 | 数值 |
|---|---|
| 六类结论一致 | **9/10** |
| 分歧 | 1 条（C43）：Flash 判 SUPPORTED 且理由自相矛盾（"证据证实是骗局"却判支持——方向读反）；主审 REFUTED 正确 → 按协议"主审结论保留除非复核指出事实性错误"裁决，**协议运转正确** |
| **C50 关键发现** | Flash 结论同为 OPINION_OR_FORECAST，但**独立点出依据失真**（"以确定语气引用 CBO 区间上限 370 万，中位估计仅 130–140 万，FactCheck 指出 CBO 未如此断言"）——正是主审（旧版规则下）放行的那个唯一硬错误 |

**结论**：① 异源复核可行性实证——跨模型盲复核管线可运行、分歧可见、裁决规则有效；② **"第二双眼睛"价值直接实证**：主审唯一硬错误（C50 依据失真）被异源复核独立揪出——若当时有异源复核层，该错误不会漏；③ 弱模型复核的风险同样实测（C43 方向读反），印证协议"复核结论不自动采纳、仅事实性错误触发改判"的设计必要性。R 档价值从理论变实测：异源 100 分档货真价实。

## 六、边界（不夸大复核的作用）

- 独立复核**降低**单模型误判风险，但**不等于第三方认证**——复核方仍是同一运行环境内的模型，评分的自评性质不变（`scoring-spec.md` §十一.1）。
- 异源复核依赖宿主的子代理/第二模型能力；没有就说没有（第三节档位④），**绝不虚构一个"复核模型"**。
- **自检复核（档位③）不是独立判断**：它只覆盖机械层（引擎重跑/摘录复读/口径核对），防的是算错抄错，防不了语义误判——标注必须带〔机械层〕限定，不得写成"已复核"。
- 复核不计入联网检索预算的检索次数，但派发子代理/新会话本身消耗轮次——轮次紧张时优先保证**问题项**复核，支持项抽样可缩至 3 条；自检复核成本近零，任何时候都不应省。
