# 引用真伪离线套件（v2.8.1）

**目的**：把"引用看着真、点开不对"这类 AI 报告头号失效，做成**可复现、可打分**的确定性检验。

裸提示审视一份报告时，通常不会逐条点开链接、比对摘录、核对来源日期与数据期间——这恰恰是工具该做的事。`cite_check` 把三项判定收敛为引擎输出：**链接可达 / 摘录逐字命中 / 来源日期与数据期间一致**。

## 跑一遍

```bash
python3 evaluation/cite_suite/run_cite_suite.py
# 合计 12/12；分类：valid 3/3，unreachable 4/4，excerpt 3/3，temporal 2/2
```

退出码 0 = 全部命中；结果同时写入 `result.json`（含每条判定的原因）。

## 文件

| 文件 | 内容 |
|---|---|
| `test_report_cite.txt` | 被审报告节选：12 条带引用的主张 |
| `ground_truth_cite.json` | 密钥：每条引用的期望结论与问题类别 |
| `pages/*.html` | 离线快照（模拟网络；快照缺失 = 不可达） |
| `run_cite_suite.py` | 运行器：逐条调 `cite_check`，对照密钥打分 |
| `result.json` | 最近一次运行的逐条结果 |

## 12 条覆盖什么

| 类别 | 条数 | 判定 |
|---|---|---|
| 真实可核 | 3 | 可达 + 摘录命中 + 时序可行 → PASS |
| 伪造/不可达 | 4 | 链接不存在或打不开 → FAIL·不可达（审计按 G2 证据不足处理，不得判支持） |
| 摘录张冠李戴 | 3 | 页面可达但引文不在页面上，或数字被替换 → FAIL·摘录未命中（按引用错配处理） |
| 时序不可能 | 2 | 2025 年报 / 2026Q1 报的数据被用来支撑 2026H1 → FAIL·时序不可能（纯逻辑反驳） |

## 边界（不要过度解读）

- 本套件证明的是**框架具备确定性引用核验能力且结果可复现**，不是"比裸提示检出更多"的两臂对照结论。两臂对照（A 套件）需在同一模型上跑基线臂，属于第 7 轮计划。
- 离线快照模拟网络：验证的是判定逻辑，不验证真实站点的反爬/登录/动态渲染。
- 只覆盖"引用是否真实、引文是否在源、时间是否可能"，**不覆盖**语义层的"引文支持但结论外推过度"——那仍归模型判定。

## 第 7 轮两臂对照（预注册）

`round7/` 是本套件的首次两臂实测：裸模型（报告 + 快照全文）vs 工具臂，各 3 次。结果：**检出打平（中位数 12/12 vs 12/12）**，工具的增量在可复现、零 token 与吞吐。设计偏差、否定结论与 7b 计划见 [`round7/README.md`](round7/README.md)。

## 接入审计

每条 `[E##]` 证据在定稿前必须跑一次 `cite_check`，把 `verdict` 与 `reason` 写进证据链；审计轨迹里没有输出 = 该主张审计未完成。`FAIL·摘录未命中` 进审计结论问题项；`FAIL·不可达` 进 G2 缺口清单，**未闭环 ≠ 通过**。
