# 核验结论框架、证据等级与评分入口（verdict-and-evidence）

> 八步决策链细节见 `verdict-decision.md`；**评分的完整公式、算例与边界见 `scoring-spec.md`（本文件只给定义，不做推导）**。

## 一、六类核验结论（Verdict）

FinProof 判定为 **6 类**。

| Verdict | 中文 | 触发条件 |
|---|---|---|
| **SUPPORTED** | 支持 | 证据直接支持主体/指标/期间/单位/口径/数值，在容差内 |
| **REFUTED** | 反驳 | 证据给出冲突事实/错误数值/错误期间/错误单位/相反方向 |
| **PARTIALLY_SUPPORTED** | 部分支持 | 主张含多组成部分，部分成立但关键部分缺失，或证据仅支持较弱表述 |
| **INSUFFICIENT_EVIDENCE** | 证据不足 | 现有证据既不能证明也不能反驳（**不得**因解析失败把明显错误主张归入此类） |
| **OPINION_OR_FORECAST** | 观点或预测 | 预测/展望/主观判断，不判真假命题 |
| **UNABLE_TO_DETERMINE** | 无法判断 | 材料缺失或不可判定 |

> 边界铁律：**REFUTED 优先于 PARTIALLY_SUPPORTED**。数值冲突（确定性复算否定）必须判 REFUTED，语义完整性再高也不得降级为 PARTIAL（见 `verdict-decision.md` 的 `guard_semantic_not_override_numeric`）。

> **类别数统一为「六类」**。历史文档中出现过的「五类」是早期任务书口径（未含"观点或预测"与"无法判断"），已废弃，勿再使用。

## 二、证据等级体系（Evidence Hierarchy，四档）

| 等级 | 分值 | 典型来源 |
|---|---|---|
| **S 级（法定/监管披露）** | 100 | 交易所公告、定期报告（年报/中报/季报）、招股书、监管文件、审计报告、法院或政府正式文件 |
| **A 级（公司直接披露）** | 70 | 公司官网、投资者关系（IR）材料、业绩说明会、公司公告性新闻稿 |
| **其他来源** | 40 | 权威财经媒体、第三方研究机构、行业协会、政府统计年鉴、公开数据库 |
| **未注明来源** | 0 | 报告给不出来源，或来源不可追溯 |

- 判定冲突时优先采信高等级；**S 级可直接闭环，A 级在 S 级缺失时顶上**。
- **其他来源不得单独定案**：只能作为线索或佐证，必须回到 S/A 级确认后才能判 SUPPORTED。
- 每条主张取**最高等级**证据计分，不重复计。
- 本档位用于计算评分的「来源权威性」维度（见 `scoring-spec.md` §3.4）。

> **变更说明**：旧版只定义 S / A 两级，"其他来源"无档位，导致「来源权威性（权重 15%）」**无法计算**，只能经验打分。本版补齐四档后该维度可复算。

## 三、报告级评分（FinProof Score，0–100）

五维加权：

| 维度 | 权重 |
|---|---|
| 可判定率（历史名「证据覆盖率」） | 25% |
| 数字与计算准确性 | 25% |
| 引用一致性 | 20% |
| 来源权威性 | 15% |
| 时间与口径一致性 | 15% |

> **完整计算方法（公式、惩罚系数、取整规则、算例、边界）见 `scoring-spec.md`——打分时必须按该文件执行，并输出五维明细 + 扣分清单。**

## 四、主张级风险分（Risk Score）

主张风险由**加总模型**计算（非乘积模型）：

```
risk_score = 基准分(按结论) + 重要性 + 置信度项 + 证据质量项 + 预测加分
           → clamp 到该结论区间
```

- 基准分（区间中值）：REFUTED 90（80–100）/ INSUFFICIENT·UNABLE 75（60–90）/ PARTIALLY 55（40–70）/ SUPPORTED 10（0–20）。
- 调整项与等级阈值（LOW / MEDIUM / HIGH / **CRITICAL**）的完整定义见 `scoring-spec.md` §6。
- 高风险优先审核对象：估值、收入、利润、增长率、重大合同、并购、监管处罚、诉讼、现金流、偿债能力、投资建议核心依据。

> **变更说明**：旧版本文档写的是乘积模型 `错误可能性 × 业务影响程度 × 证据缺口`，但**该模型从未落地**；实际实现（`backend/app/services/risk/risk_engine.py`）是加总模型。乘积模型在三因子中任一为 0 时会整条归零（例：证据缺口=0 会让高风险主张变成 0 风险），存在逻辑缺陷。**本版统一为加总模型**，并补齐了 `CRITICAL` 的触发条件（旧代码只输出三级，无 CRITICAL 分支）。

## 五、抽取模式（ExtractionMode）

`MOCK / RULES / LLM / HYBRID` —— 无 API Key 时走明确标识的 Mock 模式，结果带"Mock 模式，非真实模型输出"标识，不得伪装为真实模型结果。
