# FinProof 轻量执行卡（LITE · v2.8.0）

> **用途**：快速档唯一必读文件，自足可执行。适用于短报告（≤10 页）、单条/小批量主张核验、用户只要"快速过一遍"。与 `SKILL.md` 冲突时以 SKILL 为准；需要完整评分推导、HTML 报告、分批审协议时回读 SKILL 对应节。**容差与诚实纪律不降档。**

## 1. 容差表（硬规则，不得放宽）

| 复算类型 | 容差 | 超限 |
|---|---|---|
| 数值比对 / 累计转单季 / 比率 | 相对 **0.1%** | REFUTED |
| 同比 / 环比增长率 | **0.5pp** | REFUTED |
| 披露舍入豁免（唯一例外） | ≤**0.5%** 且须验证：报告精度下舍入能解释才豁免，标 `[舍入差异 x%]` | 超限一律 REFUTED |

**每条数值主张无论通过与否必写四元组**：复算值/报告值/绝对差/相对差% ＋ 判定来源标记〔引擎复算〕（有 shell 必调引擎，命令见 §6）/〔心算估算〕/〔逐字一致，免引擎〕。

## 2. 六类结论 + 判定校准（v2.6.1）

支持 / 反驳 / 部分支持 / 证据不足 / 观点或预测 / 无法判断。**数字守卫**：复算冲突必 REFUTED，语义不得翻案。

**判定校准（对齐专业核查"Mostly True 计真"口径）——判定语义主张时按此决策树逐步走**：
1. 先问：**主张的核心断言是否被证据支持？** 支持 → 判 **SUPPORTED**；次要不精确（边缘时点/精度/个别措辞）一律写进 `[限定：…]`，**不得作为降级理由**（例：'第二节开始停缴'实为第二节内 7.85 分钟处 → 判支持＋限定）。
2. 核心不被支持，才问第二层：是**关键组成部分缺失/方向冲突**（→ PARTIALLY_SUPPORTED），还是**证据给出相反事实**（→ REFUTED），还是**查无证据**（→ INSUFFICIENT）。
3. 数值主张不走本决策树——一律先走容差表（引擎说了算，数字守卫优先）。

## 3. 对抗五查（每条主张过一遍，一句话版）

1. **明细偏差**：四元组写了没？带内差异舍入验证过没？
2. **口径伪装**：判支持前双栏写出"报告口径 vs 证据口径"（归母↔扣非/单季↔累计/合并↔母公司/营收↔总收入）；口径未确认 → 证据不足。
3. **单位/币种**：量级（元/万/亿）与币种显式确认；pp≠%。
4. **编造因果**：归因须有机制表述或期初值方向一致；时间先后≠因果。
5. **引用三对齐 + 时序不可能（独立必做，先于页码核验）**：来源+页码/章节+报告期对齐；**来源覆盖期间早于数据所属期间 → 纯逻辑判 REFUTED（引用一致性·时序不可能），无需证据闭环，G1 不得收容，不得以"页码无法核验"替代**。有 shell 必走引擎：`temporal --source … --data …`（判定归程序）。
6. **时点漂移**：明确历史期间按该期间判；"当前/最新"行情以最接近报告日的快照为证据并标〔快照时点〕，仅有核验日数据且超容差时**不判反驳**——标〔时点漂移〕入自核清单；无法锚定时点则要求补（G1）。

## 4. G 类三条纪律

1. 每条预测/观点标注 **「依据已披露（附证据编号）/ 依据未披露」**，不得静默归"不判真假"。
2. 确定性措辞（已无悬念/确定性强/板上钉钉…）的预测 = **预测事实化，进问题项**（结论仍为观点或预测）。
3. **「依据已披露」不免责**：须复算并追溯依据本身的数字与来源；依据失真（区间上限冒充中心估计/旧数字冒充最新）→ 进问题项「依据失真」。

## 5. 引用四必填 + 铁律

每条问题项挂 `[E##]`：来源名称 / 链接（本地文件写文件名，联网给完整 URL+抓取时间）/ 定位（页码/章节）/ **逐字摘录**（「」包裹，不转述不改单位正负号）。**绝不编造 URL、页码、摘录**；冲突证据全列；查不到如实说（G1 源文件缺失 / G2 检索不可达 / G3 非公开 / G4 提取失败，未闭环 ≠ 通过）。

## 6. 引擎速查（有 shell 必用）

```bash
P=skills/finproof-verification/bin/finproof_calc.py
python3 $P match --claim 4.38 --claim-unit 亿元 --evidence-yuan 439314000   # 数值比对(0.1%)
python3 $P yoy --current 35.87 --previous 19.09                             # 同比(±0.5pp)
python3 $P quarter --h1 60 --q1 28                                          # 累计转单季
python3 $P margin --revenue 100 --cost 68                                   # 毛利率/占比
python3 $P convert --value 35.87 --unit 亿元                                # 单位换算
python3 $P temporal --source "2025年年度报告" --data "2026年上半年"            # 引用时序 → IMPOSSIBLE
python3 $P sum_check --values "117.0,88.9" --total 205.9                       # 总和一致性（分项 vs 合计）
```

```text

  其余 N 条经核验支持（附[限定]如适用，不展开）；G 类逐条标注依据已披露/未披露
证据清单（仅问题项引用的 [E##]，四必填）
自检复核一行：〔自检复核：引擎重跑 N/N 一致 · 摘录复读 N/N 一致〕
审计质量分 AQS 一行（v2.7.0，机械可算）：C 已判定/总主张 · E N_e/N_v · V 四必填完整问题项/全部问题项 · R 复核档（异源100/同源80/自检60/未复核0） · L 复验URL比 → AQS=0.30C+0.25E+0.20V+0.15R+0.10L；与报告分并列，警示"两分独立解读"

```
