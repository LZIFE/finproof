## 逐类明细

### 1. 复合句拆分残片（13 条）——根因：子句级独立成条，缺乏父句上下文

| 编号 | 主张 | 残片来源 |
| ---- | ---- | -------- |
| 01 | 同比增长12.11%（yoy_growth_revenue） | "公司2025年实现营业收入4564.52亿元，同比增长12.11%，……"——金标准 CLM-001 按整句建模，增长率子句被最佳匹配规则排除 |
| 02 | 同比下降11.84%（operating_cash_flow） | CLM-014 句的增长率子句 |
| 07 | 与营业收入基本持平 | "营业总收入为4564.52亿元，与营业收入基本持平"的谓词残片，无独立数值 |
| 08 | 同比增长6.62% | CLM-012（EPS）句的增长率子句 |
| 10 | 同比增长20.49%（2025Q1） | CLM-007 句的增长率子句（Q1） |
| 12 | 同比增长15.7%（2025H1） | CLM-008 句的增长率子句 |
| 14 | 同比增长30.0%（2025H1） | CLM-026 句的增长率子句 |
| 15 | 综合现有披露 | "综合现有披露，我们估计2025年第四季度单季营业收入超过1200亿元"的引导短语 |
| 17 | 展望2026年 | "展望2026年，公司营业收入将突破5000亿元"的时间短语 |
| 18 | 以及多元化业务整合不及预期的风险 | 风险提示列举项 |
| 21 | 主要系报告期内加大备货与渠道投入所致 | 因果子句无主语，无法独立核验 |
| 22 | 但现金流规模仍高于同期归母净利润 | 比较子句，无数值无期间 |
| 25 | 在新能源及工业技术领域 | 介词短语残片 |

**根因**：规则提取器按子句独立成条，但金标准按"整句主张"建模；子句（尤其增长率/因果/比较子句）脱离父句后无法独立匹配或核验。
**修复层**：① 规则：残片过滤（子句无指标、无数值、以"但/以及/综合/展望/主要系/在……领域"等连接词或介词开头时不独立成条）；② **子句归属（任务 5）**：增长率子句并入父句主张（如"营业收入2025同比12.11%"），残片保留为父主张的结构化字段而非独立主张。

### 2. 同一主张重复（3 条）——根因：去重键过窄 / 跨段落重复

| 编号 | 主张 | 重复对象 |
| ---- | ---- | -------- |
| 11 | 同比增长38.02%（2025Q1，归母净利） | 与 sys#228（已匹配 CLM-011）语义相同，因指标/期间/数值完全相同但键中 value_operator/nature 差异未被合并 |
| 19 | 公司2025年经营活动现金流量净额533.46亿元 | 与"全年经营活动现金流量净额533.46亿元"（已匹配 CLM-014）跨段落重复（核心观点 vs 五、现金流分析） |
| 20 | 同比下降11.84%（2025，现金流） | 与 #02 同属 CLM-014 句，且与五章节的同类子句重复 |

**根因**：结构化去重键未包含父句信息与同义归一（"全年经营现金流" vs "2025年经营活动现金流量净额"），跨段落同一主张未被合并；另有两处重复的 38.02% 子句。
**修复层**：去重（任务 6）：第三层同义去重（指标别名归一 + 数值+期间+指标相同即合并）+ 父句维度去重。

### 3. 无指标定性句 / 战略口号（4 条）——根因：过滤条件偏宽

| 编号 | 主张 | 判断 |
| ---- | ---- | ---- |
| 03 | 现金流整体稳健 | 抽象评价，无指标无数值 |
| 04 | 以新能源及工业技术与机器人为增长极的多元化布局持续兑现 | 战略口号，无法独立核验 |
| 05 | 海外OBM战略成效逐步显现 | 战略口号（注意：与金标准 CLM-019"公司持续深化……战略"不同句） |
| 13 | 环比大幅改善 | 无指标无数值的趋势短语 |

**根因**：`_has_claim_signal` 对"改善/持续/布局"等词放行，未要求可验证对象。
**修复层**：规则过滤（任务 4）：默认过滤无数字且无明确指标/事件/比较对象的定性句；LLM Prompt v2 补充"只提取能够独立验证的主张"。

### 4. 观点被错误当作事实（2 条）——根因：claim_nature 分类不准

| 编号 | 主张 | 应为 |
| ---- | ---- | ---- |
| 23 | 短期的现金流波动不改变公司稳健的造血能力 | OPINION/ASSUMPTION（现判 BUSINESS_FACT） |
| 24 | 公司经营性现金流与净利润的匹配度处于健康水平 | OPINION（现判 BUSINESS_FACT） |

**根因**："不改变/处于健康水平"等判断词未纳入 OPINION_WORDS。
**修复层**：规则（OPINION_WORDS 扩展）+ LLM Prompt v2（"观点、预测、因果必须正确分类"）。

### 6. 评测器匹配失败（0 条）

评测器修复后（冲突惩罚/引号归一化/一对一/歧义不强选），27 条无效主张全部可归因于提取层（残片/重复/过滤/分类）或金标准覆盖范围，无纯匹配逻辑错误。

## 结论与优先级

1. **子句归属（任务 5）** 是最大杠杆：13 条残片中有 10 条是"有归属的增长率子句"，并入父句后可消除大部分无效主张并提高 Recall（CLM-004/015 类问题同源）。
2. **去重（任务 6）**：跨段落重复与同义句合并可再消除 3 条，直接降低 Duplicate Rate。
3. **规则过滤（任务 4）**：定性句/口号/残片过滤可消除 4 条，提升 Precision。
4. **观点分类修正**：2 条。
5. **合理未覆盖（5 条）**：保持现状，评测如实记录。
