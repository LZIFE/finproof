# Phase 23.19 Financial Evidence Graph 审计

> 生成时间：2026-08-06 UTC

## 1. 现状：单 Block 级提取

`extract_financial_fact(block_text, ...)` 只接收**单个 block 的文本**，在块内提取：

- metric（`_metric_in`：块内最长别名命中）
- value（`_values_in`：块内千分位数字/百分比）
- unit（`_unit_in`：块内单位括号）
- period（`_periods_in`：块内年份/期间词）
- table_type / row_label / column_labels

**输入边界**：`extract_financial_fact(block_text: str, ...)` —— 单文本字符串，无页面上下文、无邻居块、无表格结构。

## 2. 单 Block 限制（实证：page 135 利润表）

利润表页（page 135）的块布局：

| block | idx | y0 | 内容 |
|---|---|---|---|
| 4441 | 1 | 73.3 | 表头："2025 年度合并及公司利润表" |
| 4442 | 2 | 144.7 | 列头："项目 附注 2025年度 2024年度"（含单位声明） |
| 4443 | 3 | 196.1 | **数值块**："四(48), 十八(3) 456,451,731 407,149,600 9…" |
| 4444 | 4 | 209.0 | **行标签块**："其中：营业收入" |
| 4445 | 5 | 392.2 | 数值块（1,694,661 1,442,940） |
| 4446 | 6 | 405.2 | 行标签块："投资收益" |
| 4454 | 14 | 729.6 | 数值块（43,945,411 38,537,237） |
| 4453 | 13 | 717.1 | 行标签块："归属于母公司股东的净利润" |

**关键发现**：
1. **指标行被拆成多个 block**：行标签（4444"其中：营业收入"）与数值（4443"456,451,731 407,149,600"）**分离**，且标签块 y0(209.0) 与数值块 y0(196.1) 相邻但不同块。
2. **单块提取必然残缺**：对 4443 提取 → metric 可能缺失（"四(48), 十八(3) 456,451,731…" 无"营业收入"字样）；对 4444 提取 → values 为空（"其中：营业收入"无数字）。**单块无法重建完整财务事实**。
3. **列头/单位在表头块**（4442"2025年度 2024年度"），数值块依赖列头上下文——块级提取无此关系。
4. **当前 extractor 无邻居块关系**：输入只有 block_text，无法知道"同页 4443 与 4444 是同一行的两部分"。

## 3. 缺失能力清单

| 缺失 | 影响 | 证据 |
|---|---|---|
| 单块限制（只接受文本） | 指标行标签与数值分离时无法重建事实 | 4443/4444 |
| 表格行重建（同页同表近 y 合并） | 行标签+数值+期间列无法聚合成一个证据单元 | 4443+4444、4453+4454 |
| 邻居块关系（前后/上下） | 不知道"哪些块属于同一表格行" | 4442 列头 vs 4443 数据行 |
| 表头/列头上下文注入 | period（2025年度/2024年度）无法从数值块推导 | 4442 列头 |
| 跨块单位传播 | 单位声明（千元）在表头块，数值块无单位 | 4441/4442 |

## 4. 修复方向（Task 2-3）

1. **Evidence Window Reconstruction（Task 2）**：对表格块按「同页 + 同表 + 近 y 坐标」合并邻居块，重建 `FinancialEvidenceObject`：
   ```
   {metric, current_value, previous_value, growth, unit, period, table_type, source_blocks}
   ```
   - 行标签块（4444）+ 数值块（4443）合并 → metric="营业收入", current=456,451,731, previous=407,149,600, growth=9.x%
   - 表头块（4442）提供 period 列头；表头/页首提供 unit
2. **Fact Retrieval Layer（Task 3）**：重排前直接按指标别名检索**财务证据对象**（而非散块），返回 candidate evidence objects。
