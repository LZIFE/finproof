# 证据引用规范（Citation Format）

> **本文件是审计报告中所有证据引用的唯一格式标准。** 目的：让用户拿到审计报告后，能**逐条点开原始链接、核对摘录原文**，自己判断结论站不站得住。
> 核验是"可追溯"的——**没有可核对来源的结论，不配写进报告**。

---

## 一、三条硬原则

1. **每条主张都必须挂证据编号**。审计报告里的每一条结论（支持/反驳/部分支持/证据不足），都必须指向 `[E##]` 编号；编号在「证据清单」中有完整出处。
2. **摘录必须逐字**。引用原文必须原样复制（含单位、正负号、括号负数表示），**不得转述、不得改写、不得四舍五入后写成原文**。改了就不是摘录。
3. **绝不编造链接**。链接只能来自真实检索结果或用户提供的文件。取不到链接就如实写"未取得可访问链接"或"未注明来源"，**宁可标低证据等级，也不编 URL**。

---

## 二、证据编号规则

- 格式：`[E01]`、`[E02]`……两位数字，按在报告中**首次出现**的顺序编号。
- 同一份证据支撑多条主张时**复用同一编号**，不重复编号。
- 编号在全篇（含主张卡、扣分清单、自核清单）中保持一致。
- 证据数量无上限，但**必须每条都有完整出处字段**（见第三节）。

---

## 三、字段定义（每条证据必填）

| 字段 | 必填 | 说明 |
|---|---|---|
| **编号** | ✅ | `[E##]` |
| **证据等级** | ✅ | `S 级`/`A 级`/`其他`/`未注明`（定义见 `verdict-and-evidence.md` 第二节） |
| **类型** | ✅ | `本地文件` 或 `联网来源` |
| **来源名称** | ✅ | 具体到文件/机构，不得只写"公司公告"。例：`2025年年度报告`、`XX公司投资者关系活动记录表`、`财联社`、`国家统计局` |
| **链接** | ✅（联网必填） | 完整可访问 URL，**后缀复验状态** `〔复验：可达 / 重定向 / 不可达(状态码) / 未复验(原因) · YYYY-MM-DD〕`（见第七节与 `web-verification.md` 第五节第 7 步）。本地文件写文件名（含扩展名）。**两者都没有 → 必须在"备注"写明原因** |
| **抓取/获取时间** | ✅ | `YYYY-MM-DD HH:MM`。本地文件写用户提供的日期 |
| **定位** | ✅ | 页码 / 章节 / 表格名 / 段落序号，越具体越好。例：`p.12「合并利润表」第 3 行` |
| **逐字摘录** | ✅ | 原文片段，用「」包裹。**不得转述** |
| **关联主张** | ✅ | 该证据支撑或反驳哪些主张，例：`支撑 #7；反驳 #11` |

---

## 四、格式模板

### 4.1 联网来源（完整形态）

```text
[E03] S 级 · 联网来源
  来源：某公司 2025 年年度报告（巨潮资讯网）
  链接：https://www.cninfo.com.cn/new/disclosure/detail?stockCode=XXXXXX〔复验：可达 · 2026-09-10 18:05〕
  抓取：2026-09-10 17:20
  定位：第 12 页「合并利润表」第 3 行
  摘录：「归属于母公司股东的净利润 1,081,776,000.00」
  关联：支撑 #9；反驳 #7（报告称单季 60 亿，此处为半年度累计）
```

### 4.2 本地文件（用户上传）

```text
[E01] S 级 · 本地文件
  来源：用户上传《2025年年度报告.pdf》
  链接：本地文件（无 URL）— 用户于 2026-09-10 提供
  抓取：2026-09-10
  定位：第 12 页「合并利润表」第 3 行
  摘录：「归属于母公司股东的净利润 1,081,776,000.00」
  关联：支撑 #9
```

### 4.3 无链接 / 来源不可追溯（必须显式标注，不得留空）

```text
[E12] 未注明 · 本地文件（报告内文）
  来源：报告内文未给出来源
  链接：未取得可访问链接（报告未标注出处）
  抓取：—
  定位：报告 p.4 第 2 段
  摘录：「据行业数据显示，市场规模达 1200 亿元」
  关联：证据不足 #15（无法回溯至一手来源）
  备注：该主张因此计入「未注明来源」档，并列入需用户自行核验清单。
```

### 4.4 付费墙 / 来源不可达（须说明已尝试）

```text
[E15] 其他 · 联网来源（不可达）
  来源：某行业数据库（Wind 终端）
  链接：https://www.wind.com.cn/（需授权，未检索）
  抓取：—
  定位：—
  摘录：—
  关联：证据不足 #19（[G2] 检索不可达）
  备注：已尝试 3 轮检索（见「聚焦再搜索记录」），仍未取得可访问来源；
        未闭环 ≠ 通过，请用户凭已授权终端自行核对。
```

## 五、主张卡内的引用写法

主张卡不重复列全部字段，只**引用编号 + 关键定位**，完整出处查证据清单：

```text
核验结果：反驳
证据引用：[E03]（S级）p.12「合并利润表」→ 详见证据清单 E03
```

**要求**：
- 每条主张至少一个引用编号；「支持」至少 1 个，「反驳」至少 1 个，「部分支持」列出支持与缺失两部分各自的编号。
- 「证据不足」须列出**已尝试检索的证据编号**（若任何一条命中），或写"无命中证据，已尝试检索见记录"。
- 「观点或预测」无须证据编号，但须核查报告是否披露依据；若披露了，列出该依据的编号（并按 SKILL §一 标注「依据已披露 / 依据未披露」）。
- **时序不可能（无需证据闭环）**：报告引用"来源 A 第 X 页"支撑某数据，而**来源 A 的覆盖期间早于该数据所属期间**（如 2025 年年报不可能披露 2026H1 数据）→ 该引用**逻辑上不可能成立**，判 REFUTED（引用一致性·时序不可能）并在主张卡注明"来源期间早于数据期间"；**此时不需要为它找证据编号**——矛盾由来源名与数据期间本身构成，页码是否可核验（G1）是次生问题，不得以此收容。

---

## 六、多证据与冲突

- **多家来源支撑同一主张**：并列编号，如 `[E03][E07]`；证据等级取**最高**者。
- **证据互相冲突**：必须全部列出，并说明采信哪一个及理由（高等级优先、一期优先）。不得只列对自己结论有利的那条。
- **跨文件矛盾**：属错误类型 #7，须在主张卡写明"两处披露冲突（E03 vs E09）"，并提示用户以哪一份为准。

---

## 七、链接失效与时效

- 链接**必须标注抓取时间**——网页内容会变，抓取时间是"我当时看到的是这个"的唯一凭证。
- 使用实时数据（行情、价格、月度统计）时，须写明**数据时点**（如"截至 2026-03-31"），不能只给抓取时间。
- **输出前链接复验（v2.5.0 起，见 `web-verification.md` 第五节第 7 步）**：定稿前对全部联网证据 URL 逐条访问，复验状态 `〔复验：可达 / 重定向 / 不可达(状态码) / 未复验(原因) · YYYY-MM-DD〕` 缀于链接字段。不可达：**不删证据**（保留原抓取时间与摘录），等级**降一档**并显著标注，支撑关键结论时优先换源补证；本地模式/预算不足：标〔未复验〕，**不得谎称已验**。复验访问计入 40 次检索预算，紧张时优先问题项与 S/A 级证据。
- 若链接在核验时已失效：标注 `链接失效（核验时无法访问）`，并保留来源名称与抓取时间，不得直接删除该证据。

---

## 八、禁止事项（违反即视为报告不合格）

- ❌ 编造 URL、编造页码、编造摘录
- ❌ 把转述/概述写成"摘录"
- ❌ 摘录时修改单位、正负号或数值（改写即失真）
- ❌ 无来源却写"据公开资料"而不标"未注明来源"档
- ❌ 只给结论不给证据编号（无法核对的结论等于没有核验）
- ❌ 只列有利证据、隐去冲突证据
- ❌ 把「付费墙未检索」与「已检索未找到」混为一谈
